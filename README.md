# Squeek Live — Community Dashboard

Community dashboard for Squeekchain that reads the official public API
(`api.squeekchain.com/v1/status`, `/v1/economy/state`) and shows live wheel
status, RPM, block height, SQK supply, cumulative work and settled rounds.

Built as a Genesis Code lane project for The Buildooooor badge.
